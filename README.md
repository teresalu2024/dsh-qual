# dsh-qual

> 质性研究全流程编排器：为高校教师、研究者提供质性研究"从选题到成文"的六阶段全流程陪跑，不限流派、不限成果类型。

## 为什么需要它

DSH 生态里的技能包多为通用框架，缺少**成体系的质性研究方法论总入口**。做质性研究（访谈、观察、文本分析）的人最大的痛点是**方法断档**——会收数据、不会分析；会访谈、不会设计；写得出、证明不了严谨。

本技能包把陈向明《质的研究方法与社会科学研究》本土方法论（六组件设计 / 14 种目的性抽样 / 三级编码 / 效度四分 / 成文三型）浓缩成一个六阶段编排器，从选题一路陪跑到成文。

## 安装

```bash
dsh plugin --profile <profile> add github.com/teresalu2024/dsh-qual
```

> 把 `<profile>` 换成你自己的 profile 名。

## 功能清单

| 阶段 | 做什么 |
|------|--------|
| Phase 1 选题 | 把模糊想法变成可回答的研究问题，定位范式 |
| Phase 2 设计 | 六组件设计卡 + 14 种目的性抽样 |
| Phase 3 进场收集 | 立场自省 + 伦理四原则 + 访谈追问 |
| Phase 4 编码分析 | 类属/情境分析 + 扎根三级编码 |
| Phase 5 效度质检 | 效度四分 + 三角互证 + 可迁移性 |
| Phase 6 成文收口 | 深描 + 成文三型 + 讨论收口 |

外加一张「卡点自动路由表」：你只要说一句"我卡在 ×××"，直接告诉你去哪个阶段。

## 使用示例

**用户**：我要做质性研究，访谈了 8 位新教师，攒了一堆录音，不知道从哪分析。

**助手**：先三问定位（数据有了吗 / 到哪一步 / 卡在哪）→ 判断你在 Phase 4 → 给出动作：先反复通读写备忘录 → 逐行开放式编码（用受访者原话命名）→ 轴心式连关系 → 选择式找核心类属 → 不断比较至饱和。
