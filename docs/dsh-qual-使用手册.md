# dsh-qual 使用手册

> 给最终用户看的白话说明。安装、用法、常见问题，一篇讲清。

---

## 1. 这是什么

**一个"质性研究全流程陪跑"的智能助手。** 你只要说一句"我要做质性研究"，它就带你从"我到底想研究什么"一路走到"论文写出来"。

它不替你做研究，而是**在你每走一步时提醒你该做什么、别踩什么坑**——像一个熟悉质性研究方法的老同事在旁边盯着。

---

## 2. 安装步骤

这个技能包是纯文本文件，DSH 会自动发现它，只需放到技能目录：

1. 打开终端，执行下面**任一**命令：
   ```bash
   # 方式一：克隆整个仓库（推荐）
   git clone https://github.com/teresalu2024/dsh-qual ~/.dsh/skills/dsh-qual

   # 方式二：只下载 SKILL.md 一个文件
   mkdir -p ~/.dsh/skills/dsh-qual
   curl -o ~/.dsh/skills/dsh-qual/SKILL.md https://raw.githubusercontent.com/teresalu2024/dsh-qual/master/SKILL.md
   ```
2. **重启 DSH 实例**（技能在实例启动时加载）。
3. 装好应该看到：对 DSH 说一句"我要做质性研究"，它会调用 `dsh-qual` 技能分阶段带你走。

## 3. 功能使用说明

### 3.1 怎么启动

对助手说下面任意一句即可：
- "我要做质性研究"
- "我的访谈数据怎么分析"
- "质性研究卡住了"

助手会先问你三个问题，把你放到对的环节：
1. 数据有了吗？
2. 现在到哪一步了？
3. 最卡你的是什么？

### 3.2 六个环节，各干什么

| 环节 | 什么时候用 | 你会得到什么 |
|------|-----------|-------------|
| ① 选题定问题 | 刚有模糊想法 | 把想法变成能落地的问题 + 该用哪种范式 |
| ② 研究设计 | 动手前 | 一张"设计卡" + 该抽哪些人 |
| ③ 进场收集 | 联系被访者、做访谈 | 知情同意要点 + 口语化访谈提纲 |
| ④ 编码分析 | 数据攒完要分析 | 怎么一步步从录音里提炼出结论 |
| ⑤ 效度质检 | 写完自查、应对审稿 | 怎么证明自己靠谱、怎么答"样本太小" |
| ⑥ 成文收口 | 动笔写论文 | 怎么写深、怎么收尾、结论别和开头对不上 |

### 3.3 卡点速查：说症状，它指路

你只要说一句人话，比如：
- "访谈挖不出东西，对方只说挺好" → 它告诉你回 ③，教你换具体情境问题追问。
- "论文写不出来" → 它告诉你回 ⑥。
- "被审稿人说结论不严谨" → 它告诉你回 ⑤。

不用记术语，说症状就行。

## 4. 常见问题（FAQ）

**Q1：装上了，但助手说没有这个技能？**
A：插件只在实例启动时加载。重启装了本插件的实例（或换个端口重新起）。

**Q2：我是做问卷统计的，能用吗？**
A：不能。它是给质性研究（访谈、观察、文本分析）用的。问卷统计请用别的工具。

**Q3：它会不会替我把论文写了？**
A：不会。它给你方法、提醒你踩坑，但编码、分析、写作得你自己做——这恰恰是质性研究该你亲手做的部分。

**Q4：它只认中文研究吗？**
A：方法论是通用的，中文、英文论文都能用；只是举例引用了本土方法论著作。

**Q5：我卡在一个很具体的环节，它会啰嗦讲一堆吗？**
A：不会。你说症状，它直接路由到对应环节给动作，不绕弯。
